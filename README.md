# Withdrawal PDF 套印工具

此工具是純前端網頁，使用 PDF.js 預覽 PDF，並以 pdf-lib 與 @pdf-lib/fontkit 寫入中文字；原始 PDF 不會上傳至伺服器。

## 使用方式

1. 使用 VS Code 的 Live Server 開啟 `index.html`（或由本機靜態網頁伺服器提供此資料夾）。
2. 選取 `Withdrawal.pdf`。若已將有權使用的 `msyhl.ttc` 放在 `index.html` 同一目錄，網頁會自動載入；否則可按「手動選取 msyhl.ttc」選取本機字型。字型檔不隨專案提交，請自行確認其使用與散布授權。
3. 若有先前下載的 JSON 設定，可在「匯入 JSON 套印設定」選取該檔；分行、日期、座標、字型大小及字色會自動套用，PDF 預覽也會同步顯示。JSON 可在選取 PDF 前或後匯入。
4. 未匯入設定時，範本本身已有「分行／民國／年／月／日」字樣，因此工具只套印空格內容：分行輸入「信義」，日期拆為民國年 115、月 11、日 20。按各自的定位按鈕，在 PDF 預覽四個空格的底線上點選文字起始位置。
5. 定位後可在各資料旁編輯 X/Y 座標微調；座標單位是 PDF 點數，X 從左往右、Y 從下往上。預設字型大小為 9 pt。按「下載 JSON 設定」可另存文字、座標與樣式設定；按「套印並下載 PDF」則產生套印文件。輸出檔名會帶有時間戳。

第三方函式庫（PDF.js、pdf-lib、@pdf-lib/fontkit）及 PDF.js worker 均由專案內的 `libs` 目錄載入，無網路也可運行。PDF 與字型只在瀏覽器記憶體中處理，不會上傳；程式會在記憶體中從 TTC 字型集合取出 Microsoft YaHei Light 供 PDF 嵌入，不會改寫原始字型檔。
