Withdrawal PDF 套印工具

在預覽上點選欄位位置，將分行別與民國日期寫入 PDF。

套印設定

1. 選擇原始 PDF

原始檔不會被修改，完成後會另存為套印版 PDF。

2. 匯入 JSON 套印設定

匯入先前下載的設定，套用套印文字、PDF 座標與字型樣式。

3. 指定字型（自動）

自動使用同目錄的 msyhl.ttc（Microsoft YaHei Light）。

4. 輸入套印內容

日期（表單已有「民國／年／月／日」）

5. 字型大小與輸出

請先選取原始 PDF。

文件預覽

尚未載入 PDF
選取 Withdrawal.pdf 後，文件會顯示在這裡。
定位時請點選欲套印文字的左下方基準位置。
